About me
Software engineer building digital products from anywhere in the world.

Desarrollador de Software Backend | Python, FastAPI | SQL, PostgreSQL | APIs y Microservicios | Azure, Windows Server | Integración de IA

I am a software developer based in Colombia, focused on backend development, services, and cloud solutions. I build REST APIs and microservices using Python and FastAPI, design and query relational databases with SQL and PostgreSQL, and integrate AI capabilities into real-world products and solutions.

I also work with Microsoft technologies, including Windows Server and Azure, with a strong interest in developing, deploying, managing, and scaling services across on-premises and cloud environments.

I am passionate about clean architecture, well-documented APIs, automation, and building reliable, secure, and scalable services. I enjoy turning complex problems into simple, efficient, and maintainable solutions by combining software development, infrastructure, cloud technologies, and artificial intelligence.
